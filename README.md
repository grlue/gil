# grlue Gil (GIL)

Public token metadata for grlue Gil, the currency of the grlue world.

- Official token (Solana): `DN355ibWteCMRihi3bnaEGn2dXTZf6yKhr3zAC8aE9LZ` — https://solscan.io/token/DN355ibWteCMRihi3bnaEGn2dXTZf6yKhr3zAC8aE9LZ
- Fixed supply 100,000,000 GIL; mint and freeze authority revoked. All supply is held in four Jupiter Lock vesting escrows.
- Any other token named GIL, including on other chains, is not the official grlue Gil.

- `gil.png` — token icon
- `gil.json` — token metadata (name, symbol, description, image)
